# STEP SEM-3 Java Lab Solutions - Week 1

This branch contains the solutions for **Week 1** (Live-Coding Practice & Assignment) for STEP SEM-3 (Java Programming).

## Files in this Branch

1. **`week1_practice.java`**
   - **Problem 1:** Rock-Paper-Scissors Game (`playRound`)
   - **Problem 2:** Palindrome Checker (Iterative, Recursive, and Array Reversal)
   - **Problem 3:** BMI Calculator for a Team (`getBmiStatus`, `printWellnessReport`)
   - **Problem 4:** First Non-Repeating Character (`findFirstNonRepeatingChar`)
   - **Problem 5:** Reverse Customer Name (`reverseCustomerName`)

2. **`week1_assignment.java`**
   - **Problem 1:** Exam Hall Seat Duplication Checker (`checkDuplicateSeats`)
   - **Problem 2:** Typing Speed Test Accuracy Checker (`checkTypingAccuracy`)
   - **Problem 3:** Traffic Signal Streak Analyzer (`findLongestStreak`)
   - **Problem 4:** Warehouse Inventory Balancer (`analyzeInventory`)
   - **Problem 5:** Movie Review Word Length Profiler (`classifyWordLengths`)

## How to Compile & Run

### Practice:
```bash
javac week1_practice.java
java week1_practice
```

### Assignment:
```bash
javac week1_assignment.java
java week1_assignment
```
