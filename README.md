# STEP SEM-3 Java Lab Solutions - Week 8

This branch contains the solutions for **Week 8: Polymorphism and Dynamic Method Dispatch** (Practice & Assignment) for STEP SEM-3 (Java Programming).

## Files in this Branch

1. **`week8_practice.java`**
   - **Problem 1:** Payment System Fee Calculation (CARD: 2%, WALLET: 1%, BANKTRANSFER: 0%)
   - **Problem 2:** Library Item Due Date Calculator (BOOK: 14 days, DVD: 7 days, MAGAZINE: 3 days)
   - **Problem 3:** Delivery Fee Calculator (STANDARD, EXPRESS, INTERNATIONAL)
   - **Problem 4:** Examination Question Grader (MCQ, TF, ESSAY keyword matching)
   - **Problem 5:** Public Transport Fare Calculator (BUS, TRAIN, METRO with peak-hour factor)

2. **`week8_assignment.java`**
   - **Problem 1:** The Canteen Billing Counter (STUDENT: 10% off, STAFF: 5% off, GUEST: +₹10)
   - **Problem 2:** Campus Parking Charge Calculator (BIKE, CAR, TRUCK)
   - **Problem 3:** The Hostel Electricity Bill (SINGLE, SHARED per occupant, AC)
   - **Problem 4:** The Festival Bonus Calculator (FULLTIME: 10%, PARTTIME: 5%, INTERN: fixed ₹2000)
   - **Problem 5:** Streaming Plan Renewal Reminder (BASIC: 30 days, STANDARD: 90 days, PREMIUM: 365 days via `LocalDate`)

## How to Compile & Run

### Practice:
```bash
javac week8_practice.java
java week8_practice
```

### Assignment:
```bash
javac week8_assignment.java
java week8_assignment
```
