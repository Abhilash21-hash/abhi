# STEP SEM-3 Java Lab Solutions - Week 6

This branch contains the solutions for **Week 6: Classes and Objects Revision** (Practice & Assignment) for STEP SEM-3 (Java Programming).

## Files in this Branch

1. **`week6_practice.java`**
   - **M1:** Student Placement Record Management (`PlacementRecord`)
   - **M2:** Hostel Mess Wallet Management (`MessWallet`) - Encapsulation & balance validation
   - **M3:** Course Credit Management (`Course`) - Constructor chaining with `this(...)`
   - **M4:** Library ID Card Management (`IdCard`) - Object reference vs duplicate instantiation (`==`)
   - **M5:** Student and College Information Management (`Student`) - Static vs instance fields

2. **`week6_assignment.java`**
   - **M1:** Library Inventory Management (`BookInventory`)
   - **M2:** Payroll Salary Management (`PayrollAccount`) - Encapsulated salary, bonus, and tax deduction
   - **M3:** Employee Profile Creation (`Employee`) - Constructor chaining for interns vs permanent staff
   - **M4:** Exam Hall Ticket Reference Management (`HallTicket`) - Pointer/reference alias comparison
   - **M5:** Employee & Company Info Management (`CompanyEmployee`) - Static company-level state tracking

## How to Compile & Run

### Practice:
```bash
javac week6_practice.java
java week6_practice
```

### Assignment:
```bash
javac week6_assignment.java
java week6_assignment
```
